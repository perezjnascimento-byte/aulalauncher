# Aura Android Launcher v2.1 (Autônoma Offline + Online · Galaxy S26)

> **Importante:** este pacote já inclui a interface completa compilada em `app/src/main/assets/`. Ao gerar o `.apk`, a Aura roda **100% independente no seu Galaxy S26**, sem marca ou servidor do Google AI Studio, mantendo internet ao vivo para clima, livros e notícias.

## Como gerar o .apk e instalar no Galaxy S26

### Opção 1 · GitHub Actions (sem PC / sem Android Studio)
1. Descompacte este `.zip` no computador.
2. Suba as pastas (`app`, `gradle`, `.github`) e arquivos para o seu repositório no GitHub.
3. No GitHub, abra **Actions** → **Build Aura Launcher APK** → **Run workflow**.
4. Ao terminar (~2 min), baixe **AuraLauncher-S26-APK** (`Aura-Launcher-S26.apk`) no seu S26 e instale.

### Opção 2 · Android Studio no computador
1. Descompacte este `.zip` e abra a pasta no **Android Studio**.
2. Conecte o Galaxy S26 via USB (Depuração USB) e toque em **Run ▶**, ou gere o APK em **Build > Build APK(s)**.

## Como definir a Aura como Tela Inicial no Samsung Galaxy S26
1. Abra **Ajustes Aura → Sobre → Definir como tela inicial**, ou:
2. **Configurações** → **Aplicativos** → **Escolher aplicativos padrão** → **App de início** → **Aura**.
